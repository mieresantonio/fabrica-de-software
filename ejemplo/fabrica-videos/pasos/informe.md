# Plantilla de informe

El paso 06 (`06-empaquetar.py`) genera `informe.md` en cada ejecución con
este formato. No se escribe a mano.

```markdown
# Informe de destilacion

Fuente: <título>
Canal: <canal>
URL: <url>
Duracion: <duración en s> s

Afirmaciones: <total>
- Nivel A: <n>
- Nivel B: <n>
- Nivel C: <n>
- Nivel X: <n>

Salidas: DESTILADO.md, registro-evidencias.json, transcripcion-normalizada.txt
```

Los recuentos salen del registro de evidencias de la ejecución, no de
ningún número escrito a mano.
